📡 Supervivencia de Red Wi-Fi (Failover a Hotspot / Failback Root)

Si el router Wi-Fi del local se apaga o se corta, el celular enciende automáticamente su propia Zona Wi-Fi (Hotspot) vía Root para que no pierdas conexión local. Cada cierto tiempo, apaga el Hotspot unos segundos, busca si volvió el router y se reconecta solo (ideal para equipos de antena única como Moto G8).
